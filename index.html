📥 Import Students From File

Upload a CSV or TXT file containing the student Name, Number and Form. Every imported student automatically receives an account.

Required columns: Name, Number, Form
Example: Name,Number,Form
John Banda,MZG001,Form 1

Default login: Library Number + default password MZUGOSS123. Students can change their password and profile photo after logging in.

📚 Import Books From File

Upload a CSV or TXT file containing book details. The system automatically creates the catalogue records.

Required columns: Title, Author, Barcode
Optional: Category, Quantity
Example: Title,Author,Category,Barcode,Quantity
Things Fall Apart,Chinua Achebe,Literature,LIT003,5

Duplicate barcodes are skipped so existing catalogue records are not overwritten.
